📚 Materi TKJ — LAN Dasar & Cisco

Belajar sebelum praktik

1. Apa itu jaringan komputer?

Jaringan adalah hubungan beberapa perangkat agar dapat bertukar data dan menggunakan sumber daya bersama. Dalam praktik TKJ, kamu perlu memahami perangkat, media transmisi, alamat IP, dan cara menguji koneksi.

2. IP Address

IP adalah alamat logis perangkat di jaringan. Contoh 192.168.10.10/24. Pada jaringan /24, subnet mask-nya adalah 255.255.255.0.

3. Switch dan Router

Switch menghubungkan perangkat dalam LAN. Router menghubungkan jaringan yang berbeda dan memiliki interface yang dapat diberi alamat IP.

4. Ping

Ping digunakan untuk menguji keterjangkauan perangkat. Jika gagal, jangan langsung menyimpulkan router rusak. Periksa kabel, interface, IP, subnet, dan gateway.

🧪 Praktikum LAN Dasar

Pemula
Skenario: Bangun koneksi PC → Switch → Router. PC menggunakan IP 192.168.10.10/24 dan router G0/0 menggunakan 192.168.10.1/24. Setelah konfigurasi, lakukan ping.

Gangguan latihan: Interface G0/0 dibuat shutdown. Temukan penyebabnya.

Langkah Praktikum

CLI Router

Router>

Perintah dasar: enable, configure terminal, interface g0/0, ip address ..., no shutdown, end, show ip interface brief, ping ...

Temukan masalah dengan bukti
Kasus: PC-01 tidak dapat melakukan ping ke router. Kamu diberi tiga petunjuk: interface router bisa saja mati, IP PC bisa salah, atau kabel belum terhubung. Jangan menebak.
